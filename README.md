# PrimeInvest Landing Page

Тестовое задание. Одностраничный лендинг для запуска рекламной кампании крипто-инвестиционной платформы.

## Функционал
- **Sticky CTA**: плавная панель действий, которая появляется при скролле (Intersection Observer API).
- **Динамический таймер**: обратный отсчет на 15 минут с сохранением состояния через `localStorage`.
- **Слайдер отзывов**: реализация на базе Swiper.js с поддержкой свайпов и адаптивностью.
- **FAQ Аккордеон**: плавная анимация раскрытия на CSS Grid.
- **Мультишаговая форма**: валидация нативных HTML5 полей и маска телефона через iMask.js.
- **Интерактивность**: анимация появления блоков при скролле (Intersection Observer).

## Технологии
- HTML5, CSS3 (BEM, Mobile-first)
- Vanilla JavaScript (ES6+)
- Swiper.js, iMask.js

## Инструкция по запуску
1. Клонируйте репозиторий: `git clone <ссылка-на-репозиторий>`
2. Откройте папку проекта в редакторе кода (например, WebStorm или VS Code).
3. Для корректной работы скриптов запустите проект через локальный сервер (например, **Live Server** в VS Code) или откройте `index.html` через сервер WebStorm.
4. Лендинг готов к просмотру в браузере.
